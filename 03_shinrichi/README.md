# 命題の真理値

基本情報技術者試験（科目A）のサンプル問題「命題の真理値」を、Pythonで全パターン総当たりして確かめる。

対応記事：基本情報技術者試験問題に挑戦しよう！「命題の真理値」～Pythonでつくって確かめる～

## 実行方法

```
cd 03_shinrichi
python3 shinrichi.py
```

## 確認していること

- P・Q・Rが取り得るすべての真偽の組み合わせ（8通り）を `itertools.product` で列挙する
- 問題文の3条件（Pは真、(not P) or Q、(not Q) or R）をすべて満たす組み合わせを絞り込む
- 条件を満たすのは P=真, Q=真, R=真 の1通りだけであることを確認する
