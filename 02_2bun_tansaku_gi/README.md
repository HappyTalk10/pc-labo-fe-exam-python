# 2分探索木

基本情報技術者試験（科目A）のサンプル問題「2分探索木になっている2分木はどれか」を、Pythonで木を組み立てて判定するプログラムで確かめる。

対応記事：基本情報技術者試験問題に挑戦しよう！「2分探索木」～Pythonでつくって確かめる～

## 実行方法

```
python3 binary_search_tree.py
```

## 確認していること

- 選択肢イと同じ値（10, 14, 16, 17, 18, 19）を持つ木が「左の子孫＜親＜右の子孫」を満たすこと
- 中間順（in-order）で節をたどると、2分探索木なら値が必ず昇順になること
- 条件を満たさない木を判定させると `is_bst()` が `False` を返すこと
