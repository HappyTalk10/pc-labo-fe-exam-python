# 関係モデル（射影・選択・結合）

基本情報技術者試験（科目A）のサンプル問題「関係モデルにおいて表Xから表Yを得る関係演算はどれか」を、SQLite＋Pythonで実際にテーブルを作り、射影・選択・結合を試して確かめる。

対応記事：基本情報の「関係モデル」をPython＋SQLiteでつくって学ぶ

設問の表Xそのもの（商品番号・商品名・価格・数量の5商品）をSQLiteのテーブルとして再現している。

## 実行方法

```
cd 05_kankei_model
python3 kankei_model.py
```

## 確認していること

- 設問の表Xと同じ内容の `商品` テーブルをPythonから作成・登録する
- 射影（`SELECT 商品番号, 数量 FROM 商品`）の実行結果が、設問の表Yと完全に一致すること
- 選択（`WHERE 価格 >= 50000`）で行だけを絞り込めること
- 結合（`JOIN ... ON ...`）で2つの表をつなげられること（設問には無い発展的な例として `仕入先` テーブルを追加）
