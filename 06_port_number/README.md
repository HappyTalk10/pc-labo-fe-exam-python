# ポート番号

基本情報技術者試験（科目A）のサンプル問題「PCとWebサーバのHTTP通信で、戻りのパケットのポート番号の組み合わせはどれか」を、Pythonのsocketでサーバーとクライアントの通信を再現して確かめる。

対応記事：基本情報技術者試験問題に挑戦しよう！「ポート番号」～Pythonでつくって確かめる～

## 実行方法

```
cd 06_port_number
python3 port_number.py
```

## 確認していること

- クライアント（PC）側のポート番号は、接続のたびにOSが自動的に割り当てること
- サーバー（Webサーバー）側のポート番号（ここでは8080番、設問では80番）は固定であること
- サーバーからの戻りのパケットでは、送信元・宛先のポート番号が行きのパケットと入れ替わること
