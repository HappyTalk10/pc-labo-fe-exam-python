# システムの稼働率

基本情報技術者試験（科目A）のサンプル問題「サーバ1台・クライアント3台（並列）・プリンタ2台（並列）から成るシステムの稼働率を表す計算式はどれか」を、Pythonのモンテカルロ・シミュレーションで検証する。

対応記事：基本情報技術者試験問題に挑戦しよう！「システムの稼働率」～Pythonでシミュレーションする～

## 実行方法

```
cd 08_kadouritsu
python3 kadouritsu.py
```

## 確認していること

- 設問で導いた計算式 `a × (1-(1-b)^3) × (1-(1-c)^2)` による理論値
- 各装置の稼働・停止を乱数で再現し、10万回試行してシステム全体が稼働した割合を数えるシミュレーション値
- 理論値とシミュレーション値がほぼ一致すること（試行回数を増やすほど収束する）

`random.seed(42)` で乱数の種を固定しているため、実行するたびに同じ結果になる。
