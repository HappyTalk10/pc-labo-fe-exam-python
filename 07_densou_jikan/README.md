# 回線の伝送時間

基本情報技術者試験（科目A）のサンプル問題「1.5Mビット/秒の伝送路で12Mバイトを転送する伝送時間（伝送効率50%）」を、Pythonの関数で計算し、条件を変えて比較する。

対応記事：基本情報技術者試験問題に挑戦しよう！「回線の伝送時間」～Pythonで計算・比較する～

## 実行方法

```
cd 07_densou_jikan
python3 densou_jikan.py
```

## 確認していること

- 「データ量（ビット換算）÷ 実効速度（伝送速度×伝送効率）」の計算式が、設問の正解（128秒、選択肢エ）と一致すること
- 伝送効率を25%〜100%まで変えて比較すると、効率が下がるほど伝送時間が長くなること
- 伝送効率を掛け忘れた（100%として計算した）場合の結果が、誤答の選択肢ウ（64秒）と一致すること
